## 🛠️ Tech

- **Language:** Java
- **Method:** Solve on paper/IDE → test on LeetCode → push here for tracking + revision.
- Each file includes a runnable `main` for quick local testing where applicable.

## 🎯 Why this repo exists

Consistency over intensity. This is a daily-habit tracker as much as a code archive — every solve is logged against a structured roadmap, so gaps in topic sequencing show up fast and get corrected.
